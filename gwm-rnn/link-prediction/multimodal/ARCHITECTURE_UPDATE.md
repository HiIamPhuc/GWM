# Architecture Update: Relation Embeddings Removal

## Summary

Removed relation text embeddings from the multimodal GWM-RNN architecture to align with previous work (MMKG, MoSE, IKRL) and enable reusing precomputed entity embeddings.

## Changes Made

### 1. **Model Architecture** (`model.py`)

**Before**:
```python
# Relation fusion: text + structural
self.relation_fusion = MultimodalFusionLayer(
    text_dim=text_dim,
    image_dim=image_dim,  # zeros
    structural_dim=structural_dim,
    ...
)

# Forward pass
fused_relation = self.relation_fusion(relation_text_norm, zeros, relation_structural_norm)
```

**After**:
```python
# Relation: ONLY structural embeddings
self.relation_projector = nn.Sequential(
    nn.Linear(structural_dim, fusion_dim),
    nn.LayerNorm(fusion_dim),
    nn.ReLU(),
    nn.Dropout(dropout)
)

# Forward pass
fused_relation = self.relation_projector(relation_structural_norm)
```

**Parameters Removed**:
- `relation_text_emb` from `forward()` signature
- `MultimodalFusionLayer` for relations (replaced with simple projection)

---

### 2. **Dataset** (`dataset.py`)

**Removed**:
- `relation_text_embeddings` parameter from both:
  - `MultimodalKGDataset.__init__()`
  - `MultimodalKGEvaluationDataset.__init__()`
- `relation_text_emb` from dataset `__getitem__()` return dict
- `relation_text.pt` loading from `load_multimodal_data()`
- `relation_text_embs` from `create_multimodal_dataloaders()` parameters

**Impact**:
- No longer need to prepare/load relation text embeddings
- Datasets only load entity embeddings (text + image)
- Relation information comes from learnable structural embeddings

---

### 3. **Training** (`train.py`)

**Removed**:
```python
# Old
relation_text_emb = batch['relation_text_emb'].to(device)

predicted_tail, _ = model(
    ...
    relation_text_emb=relation_text_emb,  # REMOVED
    ...
)
```

**New**:
```python
predicted_tail, _ = model(
    head_text_emb=head_text_emb,
    head_image_emb=head_image_emb,
    head_image_mask=head_image_mask,
    head_entity_ids=head_ids,
    relation_ids=relation_ids,  # Only IDs needed for structural lookup
    entity_context_text=entity_context_text_train,
    entity_context_image=entity_context_image_train,
    entity_context_image_mask=entity_context_image_mask_train
)
```

---

### 4. **Inference** (`inference.py`)

**Removed**:
- `self.relation_text_embs` loading
- `relation_text_emb` from inference forward pass
- Derive `num_relations` from triples instead of relation embeddings

---

### 5. **Documentation** (`README.md`)

**Updated**:
- Architecture diagram: Relations now show structural-only
- Added rationale section explaining why no relation text
- Aligned with previous multimodal KG work

## Why This Change?

### 1. **Aligns with Previous Work**
Previous multimodal KG papers (MMKG, MoSE, IKRL) focus on:
- **Entity multimodality**: Entities have text + images
- **Relation structure**: Relations learned from graph structure

### 2. **Enables Reusing Precomputed Embeddings**
You now have:
- `MKG-W-textual.pth` - Entity text embeddings ✓
- `MKG-W-visual.pth` - Entity visual embeddings ✓
- No need for relation text embeddings ✓

### 3. **Relations are Naturally Structural**
- Relations connect entities (graph edges)
- Their meaning comes from connectivity patterns
- Example: `capital_of` learned from `(?, capital_of, capital_city)` patterns

### 4. **Simpler Architecture**
- Fewer parameters to train
- Faster training
- Easier to implement and debug

---

## Impact on Model Capacity

**Before**:
```
Entity: Text (768) + Image (512) + Structural (768) = 1024 fused
Relation: Text (768) + Structural (768) = 1024 fused
```

**After**:
```
Entity: Text (768) + Image (512) + Structural (768) = 1024 fused
Relation: Structural (768) → 1024 projected
```

**Change**:
- Removed ~600K parameters (relation text projections)
- Relations still have same dimensionality (1024)
- Learnable structural embeddings capture relation semantics

## How to Use With Precomputed Embeddings

### Step 1: Load Entity Embeddings

```bash
# Load textual embeddings
python load_precomputed_embeddings.py \
    --embedding_path "MMKG_Research/src_data/embeddings/MKG-W-textual.pth" \
    --output_dir "./data/MKG-W" \
    --dataset MKG-W

# Load visual embeddings
python load_precomputed_embeddings.py \
    --embedding_path "MMKG_Research/src_data/embeddings/MKG-W-visual.pth" \
    --output_dir "./data/MKG-W" \
    --dataset MKG-W
```

### Step 2: Add Triples

Copy or link your triple files:
```
data/MKG-W/
├── triples/
│   ├── train.pt
│   ├── valid.pt
│   └── test.pt
└── embeddings/
    ├── entity_text.pt       ← From MKG-W-textual.pth
    ├── entity_image.pt      ← From MKG-W-visual.pth
    └── entity_image_mask.pt ← Generated by script
```

### Step 3: Generate Context Embeddings

```bash
python generate_context_embeddings.py \
    --data_dir ./data/MKG-W \
    --aggregation mean \
    --top_k 20
```

### Step 4: Train

```bash
python train.py \
    --data_dir ./data/MKG-W \
    --batch_size 256 \
    --num_negatives 10 \
    --learning_rate 5e-4 \
    --epochs 100
```

**MKG-W** (15,000 entities, ~18,000 images):
- Expected MRR: 25-35%
- Hits@1: 18-28%

- Expected MRR: 22-30%
- Hits@1: 15-23%
